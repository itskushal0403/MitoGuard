# MitoGuard

Imposter-aware, scanner-robust mitotic figure counting for H&E histopathology. YOLO11 candidate detectors and a
LoRA-fine-tuned pathology foundation model (Phikon), with conformal 90% count intervals and a grade-ambiguity flag.

Code, results and model card: https://github.com/itskushal0403/MitoGuard. Research software, not a medical device.
